# ComfyUI Imagen Bridge

Tracked ComfyUI custom-node and page integration for Imagen PS. It exposes only:

- `ImagenWorkflowBindingContract`
- `ImagenWorkflowTypeContract`
- `GET /imagen-ps/bridge/status`
- the fixed page Bridge commands `handshake`, `list-workflows`, `submit-workflow`, `reset`, and `dispose`

The same envelope runs over a browser iframe pinned to `window.parent` or a Photoshop UXP WebView pinned to `window.uxpHost`. UXP replies use the host's one-argument `postMessage` contract.

The integration does not own workflow-contract rules. Generate its runtime schema, validators, fixtures, and compatibility tuple from the canonical execution package:

```sh
python3 scripts/sync_contract.py
python3 scripts/sync_contract.py --check
```

Both commands fail when canonical source is absent or generated bytes drift. Default tests are local and mock-only:

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/*.test.mjs
```
